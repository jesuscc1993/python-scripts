# Copy Files

## Description

Various scripts for copying, backing up and restoring files.

## Scripts

### [backup_and_replace_files.py](backup_and_replace_files.py)

Copies new/updated files from a source to a destination, replacing existing ones.

### [backup_file.py](backup_file.py)

Backs up a single file, optionally watching it and re-backing it up on an interval.

### [backup_folder.py](backup_folder.py)

Copies new/updated files from a source to a destination without replacing existing ones.

### [copy_folder_images.py](copy_folder_images.py)

Copies `cover.jpg` / `desktop.ini` / `folder.jpg` / `icon.ico` files from a source to a destination.

### [restore_backups_in_folder.py](restore_backups_in_folder.py)

Restores every `.bak` file found in a folder.

### [restore_file.py](restore_file.py)

Restores a single backed up file.
