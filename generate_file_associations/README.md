# Generate File Associations

## Description

Windows-only scripts for managing file type associations and their icons.

## Scripts

### [generate_file_associations.py](generate_file_associations.py)

Creates file associations and icons based on the mappings defined in `associations.json`.

### [override_sagethumbs.py](override_sagethumbs.py)

Re-registers SageThumbs as the thumbnail handler for common image extensions.
