# Group

## Description

Collection of scripts for grouping files into subfolders.

## Scripts

### [group_files_by_chapter.py](group_files_by_chapter.py)

Groups manga/comic files by chapter number.

### [group_files_by_name.py](group_files_by_name.py)

Groups files that share the same name, ignoring extension.

### [group_files_by_series.py](group_files_by_series.py)

Groups files by series name, optionally normalizing names beforehand.

### [group_files_by_tags.py](group_files_by_tags.py)

Groups files by their trailing `[tag]`.

### [group_game_shortcuts_by_client.py](group_game_shortcuts_by_client.py)

Groups `.url` shortcuts by the game client they launch (e.g. Epic Games).
