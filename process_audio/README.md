# Process Audio

## Description

Collection of scripts for downloading and converting audio.

## Scripts

### [convert_to_mp3.py](convert_to_mp3.py)

Recursively converts audio files to MP3, then deletes the originals.

### [download_from_spotify.py](download_from_spotify.py)

Downloads a Spotify track/album/playlist.

### [download_from_yt.py](download_from_yt.py)

Downloads the audio of a YouTube video/playlist as MP3.
