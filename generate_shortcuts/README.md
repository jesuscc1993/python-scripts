# Generate Shortcuts

## Description

Generates `.lnk` shortcuts for ROMs and Steam games.

## Scripts

### [generate_rom_shortcuts.py](generate_rom_shortcuts.py)

Matches emulator binaries with ROMs and generates a shortcut for each one.

### [generate_steam_shortcuts.py](generate_steam_shortcuts.py)

Scans your installed Steam libraries and generates a shortcut for each game.
