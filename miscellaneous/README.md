# Miscellaneous

## Description

Various standalone scripts that don't fit into other categories.

## Scripts

### [relativize_folder_icons.py](relativize_folder_icons.py)

Iterates subfolders and replaces IconResources with relative paths when possible.
Useful to retain folder icons when moving folders between drives or changing drive letters.

### [flatten_subfolders.py](flatten_subfolders.py)

Moves all files from subfolders up into their parent folder, then deletes the subfolders once they're empty.
