# Process Books

## Description

Collection of scripts for processing ebooks.

## Scripts

### [cleanup_contents.py](cleanup_contents.py)

Strips unwanted elements/attributes from an ebook's HTML contents.

### [generate_covers.py](generate_covers.py)

Generates a cover image for each ebook, based on its title/series/author.

### [prefix_order_by_year.py](prefix_order_by_year.py)

Prefixes ebook folders with their publication order, parsed from a reference order text file.

### [update_covers.py](update_covers.py)

Replaces the embedded cover image inside each ebook with its `cover.jpg` / `folder.jpg`.
