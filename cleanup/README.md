# Cleanup

## Description

Various scripts for freeing up disk space.<br>
Windows only.

## Scripts

### [clean_browsers.py](clean_browsers.py)

Deletes Chrome and Firefox cache folders.

### [clean_package_cache.py](clean_package_cache.py)

Clears the npm, yarn, pip and DISM component caches.<br>
Requires admin privileges.

### [clean_system_files.py](clean_system_files.py)

Deletes temporary files and crash dump files.
